## 📂 Project Structure

```text
profile-website/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

### `index.html`

Contains the main structure and content of the profile website.

### `style.css`

Controls the appearance of the website, including:

* Colors
* Fonts
* Spacing
* Layout
* Cards
* Header
* Footer

### `script.js`

Contains JavaScript code used to add interactive behaviour to the website.

## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.

You can also open the folder in **VS Code** and use the **Live Server** extension.
